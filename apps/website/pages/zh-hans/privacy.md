# 隐私说明

**最后更新：** 2026 年 11 月 20 日

Worship Q 的设计原则是尽量少了解你。没有账号，应用内没有跟踪，也没有广告。本页说明 Worship Q 应用、免费的 Worship Q 公共服务器和本网站会处理哪些信息、保留多久，以及还涉及哪些第三方。

**我们是谁：** Worship Q 及其公共服务器由 IHS Technology 运营。有关你的数据的问题和请求，请发邮件至 [hello@ihs.technology](mailto:hello@ihs.technology)。

## 简要说明

- 你的诗歌、流程表、录音和设置保存在你的电脑上；如果教会有自己的服务器，则保存在教会服务器上。这些内容从不会发送给我们。
- 公共服务器只做中转，然后删除：幻灯片在电脑取得后立即删除，其他内容一天内删除。
- 我们不保存姓名、账号或任何内容。只有在服务器因达到限额而拒绝请求时，才会记录网络地址（IP 地址），日志在 14 天后删除。

## Worship Q 应用

应用没有账号、没有统计分析，也不发送崩溃报告。你在应用里制作的内容保存在你的电脑上。应用只在以下情况使用互联网：

- **检查更新：** 打开后约十秒，以及之后每六小时，向 GitHub 查询是否有新版本。和任何下载一样，GitHub 会看到你电脑的网络地址。
- **公共服务器：** 当工作区没有连接教会服务器时，用于下面所说的功能。
- **你投影的网站**，以及**教会设置的圣经译本和服务**，由你自己选择。
- **现场音频：** 为了在设备之间找到连接路径，电脑和手机会向 STUN 服务器（Google 的 `stun.l.google.com`）查询自己的公网地址。Google 会看到这个地址，但看不到任何音频内容。

**教会服务器**由你的教会运行，而不是我们。它保存什么（诗歌、备份、录音、投影记录等）由教会决定，请询问负责的同工。本页不涵盖教会服务器。

## 公共服务器

`public.worship-q.com` 为没有教会服务器的电脑提供手机遥控、圣经经文、幻灯片转换和现场音频。它运行在 Amazon Web Services 位于英国伦敦的服务器上，前面有 Amazon CloudFront。

### 经过服务器的内容和保留时间

| 内容                                                          | 保留                                                                                                                |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 你导入的幻灯片、PDF 和照片，以及转换出的幻灯片图片            | 电脑确认已取得后立即删除；未确认的一天内删除                                                                        |
| 手机遥控的消息、手机上显示的幻灯片小图，以及手机上的 OBS 画面 | 不保存：只在电脑和手机都连接时中转                                                                                  |
| 现场音频                                                      | 不保存、不录音：在电脑和最多两位收听者之间中转。网络需要时，经过同一主机上的中继服务器（TURN）                      |
| 圣经经文                                                      | 经文出处会转给 Free Use Bible API，对方看到的是我们的服务器，而不是你。经文内容在内存中最多保留 10 分钟，不与你关联 |
| 诗歌、流程表、备份和录音                                      | 从不发送到公共服务器                                                                                                |

### 服务器对你的电脑知道什么

- **一个工作区编号和一把设备密钥**，都是随机生成的，在电脑第一次使用公共服务器时创建。密钥只以加密散列的形式保存，并记录最后使用的时间。它们都不包含你、你的教会或你的电脑的名称。工作区 90 天未使用后即被删除。
- **这份应用的随机编号**，由电脑发送，用来按每份应用计算限额（例如每天 100 份幻灯片和照片）。它只保存在内存中，保留时间不超过限额的计算周期（最长一天），从不写入磁盘或日志。
- **你的网络地址**，每个互联网请求都会带有。它保存在内存中，用来按地址计算限额，最长一天。

### 日志

- 服务器日志为每个请求记录时间、请求的内容（不含细节，所以没有经文搜索或出处）和结果。日志不记录你的网络地址，只有因达到限额而被拒绝的请求例外：那一行会记录地址和所达到的限额。
- 中继服务器（TURN）会记录它中转音频的每台设备的地址。
- 日志在 14 天后删除。途中不保留其他访问日志。

保留日志只是为了维持服务运行和防止滥用，不作其他用途。

## 本网站

worship-q.com 托管在 GitHub Pages 上，GitHub 会保留自己的访问日志。我们使用 Cloudflare Web Analytics 统计访问量：它不设置 Cookie，也不会跨网站跟踪你，我们只看到总数。本网站没有表单，也不需要登录。

## 法律信息

根据英国数据保护法（UK GDPR），IHS Technology 是公共服务器和本网站的数据控制者。我们依据的是正当利益：提供你使用的服务，并让服务对所有人安全、公平。我们不出售数据，不做用户画像，也不用于广告。

你可以要求查看、更正或删除与你有关的数据，或反对其使用。由于我们不保存姓名或账号，通常无法分辨哪些数据属于你；请写信至 [hello@ihs.technology](mailto:hello@ihs.technology)，我们会尽力协助。无论如何，你停止使用的工作区会在 90 天后删除。你也可以向英国[信息专员办公室（ICO）](https://ico.org.uk/make-a-complaint/)投诉。
