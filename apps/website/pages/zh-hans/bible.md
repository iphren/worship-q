# 圣经经文，随时投影

讲员临时提到一段不在流程表中的经文？使用 Worship Q，几秒钟就能找到并显示在投影屏幕上，还可以并排显示两个圣经译本。

![投影屏幕上的诗篇 23 篇，和合本与英王钦定本（KJV）并排显示，带有经节编号](/screenshots/zh-hans/slideshow-bible.webp)

## 查找经文

- **直接输入出处**：例如 `马可福音15:5-6`、`可15:5-6`，也支持 `Mark 15:5-6` 等英文写法。
- **按书卷查找**：先选书卷和章节，再选择起始、结束经节；也可以跨章选择。
- **关键词搜索**：例如输入 `爱你们的仇敌`。是否支持关键词搜索取决于所选译本。
- 在诗歌搜索框中输入经文出处，也可以直接跳转到圣经查找页面。

## 投影或加入流程表

- 选择 **投影 ▶**，经文会插入当前显示项目的后面，并立即出现在投影屏幕上。
- 选择 **加入流程表**，经文会加入相同的位置，但不会马上显示，适合提前准备稍后要读的经文。
- 经文与诗歌一样，都是流程表中的独立项目。你可以调整顺序、移除项目，或重新选择经节和译本。幻灯片按完整经节分页，并显示经节编号及译本名称。
- 经文可以使用独立背景，不受诗歌背景设置影响。
- 使用手机遥控时，也可以临时把经文加入正在使用的流程表。

## 两个译本，逐节对应

双译本模式会尽量让相同的经节出现在同一张幻灯片上。若两个译本的经节划分不同，例如一个译本将两节合并，Worship Q 会在操作界面中显示说明，方便同工核对。这些说明不会出现在投影屏幕上。

## 支持哪些译本？

经文功能需要连接教会自己的免费 Worship Q 服务器（参见[服务器设置](/server/#经文)）。无需 API 密钥，就能使用和合本、英王钦定本（KJV）、Berean Standard Bible 等译本。教会也可以配置自行申请的 API 密钥，使用 NIV（英式英语版）、NKJV、NLT、ESV 等其他译本。

教会可以选择开放哪些译本，每个工作区最多同时显示两个。

**已经加入流程表的经文，即使临时断网，也能继续投影。**
