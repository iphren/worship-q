# Worship Q 与其他教会投影软件对比

如果你正在寻找 ProPresenter 或 EasyWorship 的免费替代方案，或者想了解 Worship Q 与 OpenLP、FreeShow、Proclaim 的差异，可以先从价格、支持平台和是否开源这几个方面比较。

|               | 价格               | 运行平台                                                  | 开源           |
| ------------- | ------------------ | --------------------------------------------------------- | -------------- |
| **Worship Q** | 免费，没有付费版   | macOS 11 或更高版本、Windows 10 或更高版本                | 是，MIT 许可证 |
| ProPresenter  | 付费订阅（新用户） | macOS、Windows                                            | 否             |
| EasyWorship   | 付费订阅           | macOS、Windows                                            | 否             |
| Proclaim      | 付费订阅           | macOS、Windows；Proclaim Pro 还支持浏览器、iOS 和 Android | 否             |
| OpenLP        | 免费               | Windows、macOS、Linux                                     | 是，GPL        |
| FreeShow      | 免费               | Windows、macOS、Linux                                     | 是，GPL 3.0    |

以上信息根据各产品截至 **2026 年 11 月 17 日** 的官方介绍和支持文档整理。价格、平台及功能可能调整，请在选择前查阅各产品的最新资料。

## Worship Q 有什么特点？

- **真正免费，也无需注册账号。** 没有订阅费用或付费版本。诗歌共享、手机遥控和经文查询所需的教会服务器同样免费，可以部署在教会自己的设备上，由教会管理内容。
- **同一张幻灯片显示多种语言。** 一句歌词与对应译文可以放在一起；中文诗歌还支持拼音、首字母和繁简体搜索。[了解多语言歌词](/multilingual-lyrics/)
- **圣经经文双译本对照。** 快速输入经文出处，即可查找经文，并让两个译本逐节对应显示。[了解经文功能](/bible/)
- **兼顾现场投影与 OBS 直播。** 除了投影，还支持透明背景的歌词字幕，并可通过电脑或手机控制 OBS 场景、直播和录制。[了解 OBS 功能](/obs/)
- **多台电脑同步投影。** 主控电脑发生故障时，另一台可以接管并从原来的幻灯片继续。在同一局域网内，断网后也能保持同步。[了解多机协作](/several-computers/)
- **无需安装手机应用。** 扫描二维码、经电脑端批准后，就能在手机浏览器中遥控投影。[了解手机遥控](/phone-remote/)

## 还需要考虑哪些限制？

- **暂不支持 Linux。** Worship Q 目前提供 macOS 和 Windows 版本；OpenLP、FreeShow 也支持 Linux。
- **暂不支持从其他软件直接导入诗歌。** 目前需要将歌词复制粘贴到 Worship Q 中。如果教会需要迁移工具，可以发邮件至 [hello@ihs.technology](mailto:hello@ihs.technology) 联系我们。
- **项目仍在发展中。** 成熟的软件经过多年积累，可能提供更多高级功能，例如舞台显示、丰富的媒体资源管理，以及更完善的社区支持。
- **Windows 版尚未进行代码签名。** 首次运行时，Windows 可能显示安全确认提示。

你可以先[下载 Worship Q](/)，与目前使用的软件对照试用。基本单机功能无需账号，也不依赖互联网。
