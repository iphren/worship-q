# Worship Q 与其他软件比较

在找 ProPresenter 或 EasyWorship 的免费替代品，或者在比较 Worship Q 和 OpenLP、FreeShow 或 Proclaim？下面按各自公开的资料来比较。

|               | 价格               | 运行平台                                                  | 开源           |
| ------------- | ------------------ | --------------------------------------------------------- | -------------- |
| **Worship Q** | 免费，没有付费版   | macOS 11 或更高版本、Windows 10 或更高版本                | 是，MIT 许可证 |
| ProPresenter  | 付费订阅（新用户） | macOS、Windows                                            | 否             |

## Worship Q 的不同之处

- **免费，没有任何保留。** 没有订阅，没有付费版，不需要账号。提供共享、手机遥控和经文的教会服务器也是免费的，而且运行在你自己的机器上，所以你的诗歌留在你的教会。
- **一张幻灯片上显示两种或更多语言。** 诗歌的每一行和它的翻译在同一张幻灯片上，中文诗歌可以用拼音或首字母找到，简体繁体都可以。[详情](/multilingual-lyrics/)
- **两个译本的经文并排显示，** 逐节对齐，输入经文出处就能找到。[详情](/bible/)
- **也为直播而设计：** 为 OBS 提供字幕叠加层，并可以从 Worship Q 或手机控制 OBS 的场景、推流和录制。[详情](/obs/)
- **多台电脑，一个演示，** 主控演示的电脑出故障时，另一台电脑从同一张幻灯片继续；没有互联网时，场地的 Wi-Fi 也能让它们保持同步。[详情](/several-computers/)
- **手机就是遥控器，** 不需要安装应用：扫描二维码，批准一次手机即可。[详情](/phone-remote/)

## 其他软件领先的地方

- **没有 Linux 版本。** Worship Q 运行在 macOS 和 Windows 上；OpenLP 和 FreeShow 也能在 Linux 上运行。
- **还不能从其他软件导入。** 来自 ProPresenter、EasyWorship 或 OpenLP 的诗歌要以文字粘贴进来。如果你的教会需要导入功能才能转过来，请发邮件到 [hello@ihs.technology](mailto:hello@ihs.technology)。
- **一个年轻的项目。** 成熟的产品有多年积累的功能，例如舞台显示器和丰富的媒体库，也有庞大的社区。
- **Windows 应用还没有经过 Microsoft 签名，** 所以第一次打开前 Windows 会询问一次。
