# Several computers, one presentation

The projector computer, the streaming computer and the laptop at the front can all show the
same slide, and any of them can run it.

## One live presentation

With your church's server, every computer of a workspace shares one presentation. The first
to open holds it; the others follow and show the same slide on their own screens and stream
overlays. Anyone can click a slide, go live with another date or edit the live run sheet from
any of them, and the others see each edit in a banner.

## When a computer fails

If the presenting computer stops, the others say so. Choose **Carry on here** on one of them:
it continues from the same slide. When the first computer comes back, it follows.

**Use this computer** hands the presentation to another computer without changing anything on
any screen.

## A projector computer that only follows

**Viewer mode** is for a computer that should only show the presentation: it never starts or
holds one, and reopens as a viewer. With nothing live, it shows **Waiting for presentation**.

## Without internet at the venue

Computers on the same Wi-Fi keep presenting together when the internet drops. Settings says
how each computer is connected: **On this network** or **Through the church server**.
