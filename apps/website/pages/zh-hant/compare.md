# Worship Q 與其他教會投影軟體比較

如果你正在尋找 ProPresenter 或 EasyWorship 的免費替代方案，或想了解 Worship Q 與 OpenLP、FreeShow、Proclaim 的差異，可以先從價格、支援平台和是否開源這幾個面向比較。

|               | 價格                 | 執行平台                                                  | 開源           |
| ------------- | -------------------- | --------------------------------------------------------- | -------------- |
| **Worship Q** | 免費，沒有付費版     | macOS 11 或更高版本、Windows 10 或更高版本                | 是，MIT 許可證 |
| ProPresenter  | 付費訂閱（新使用者） | macOS、Windows                                            | 否             |
| EasyWorship   | 付費訂閱             | macOS、Windows                                            | 否             |
| Proclaim      | 付費訂閱             | macOS、Windows；Proclaim Pro 還支援瀏覽器、iOS 和 Android | 否             |
| OpenLP        | 免費                 | Windows、macOS、Linux                                     | 是，GPL        |
| FreeShow      | 免費                 | Windows、macOS、Linux                                     | 是，GPL 3.0    |

以上資訊依據各產品截至 **2026 年 11 月 17 日** 的官方介紹和支援文件整理。價格、平台與功能可能調整，選擇前請先查閱各產品的最新資訊。

## Worship Q 有哪些特色？

- **完全免費，也不必註冊帳號。** 沒有訂閱費或付費版本。詩歌共享、手機遙控與經文查詢所需的教會伺服器同樣免費，可以部署在教會自己的裝置上，由教會管理內容。
- **在同一張投影片顯示多種語言。** 一句歌詞與對應譯文可以放在一起；中文詩歌還支援拼音、首字母和繁簡字搜尋。[了解多語言歌詞](/multilingual-lyrics/)
- **聖經經文雙譯本對照。** 輸入經文出處就能快速查找，並將兩個譯本逐節對應顯示。[了解經文功能](/bible/)
- **兼顧現場投影與 OBS 直播。** 除了投影，也支援透明背景的歌詞字幕，並能透過電腦或手機控制 OBS 場景、直播與錄製。[了解 OBS 功能](/obs/)
- **多台電腦同步投影。** 主控電腦故障時，另一台可以接管並從原來的投影片繼續。已在兩台電腦上驗證：斷網後，同一區域網路中的電腦仍能繼續同步。[了解多機協作](/several-computers/)
- **不需安裝手機應用程式。** 掃描 QR 碼並經電腦端批准後，就能在手機瀏覽器中遙控投影。[了解手機遙控](/phone-remote/)

## 還需要考慮哪些限制？

- **目前不支援 Linux。** Worship Q 提供 macOS 和 Windows 版本；OpenLP、FreeShow 也支援 Linux。
- **目前無法直接從其他軟體匯入詩歌。** 需要先把歌詞複製貼上到 Worship Q。如果教會需要轉移工具，可以寄信至 [hello@ihs.technology](mailto:hello@ihs.technology) 與我們聯絡。
- **專案仍在發展中。** 成熟的軟體經過多年累積，可能提供更多進階功能，例如舞台顯示、豐富的媒體資源管理，以及較完善的社群支援。
- **Windows 版尚未完成程式碼簽署。** 首次執行時，Windows 可能會顯示安全確認提示。

你可以先[下載 Worship Q](/)，與目前使用的軟體比較試用。基本單機功能不需帳號，也不依賴網際網路。
