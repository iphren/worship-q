# 隱私說明

**最後更新：** 2026 年 11 月 20 日

Worship Q 的設計原則是盡量少了解你。沒有帳號，應用程式內沒有追蹤，也沒有廣告。本頁說明 Worship Q 應用程式、免費的 Worship Q 公共伺服器和本網站會處理哪些資訊、保留多久，以及還涉及哪些第三方。

**我們是誰：** Worship Q 及其公共伺服器由 IHS Technology 營運。有關你的資料的問題和請求，請寄電子郵件至 [hello@ihs.technology](mailto:hello@ihs.technology)。

## 簡要說明

- 你的詩歌、流程表、錄音和設定儲存在你的電腦上；如果教會有自己的伺服器，則儲存在教會伺服器上。這些內容從不會傳送給我們。
- 公共伺服器只做中轉，然後刪除：投影片在電腦取得後立即刪除，其他內容一天內刪除。
- 我們不保存姓名、帳號或任何內容。只有在伺服器因達到限額而拒絕請求時，才會記錄網路位址（IP 位址），日誌在 14 天後刪除。

## Worship Q 應用程式

應用程式沒有帳號、沒有統計分析，也不傳送當機報告。你在應用程式裡製作的內容儲存在你的電腦上。應用程式只在以下情況使用網際網路：

- **檢查更新：** 開啟後約十秒，以及之後每六小時，向 GitHub 查詢是否有新版本。和任何下載一樣，GitHub 會看到你電腦的網路位址。
- **公共伺服器：** 當工作區沒有連線教會伺服器時，用於下面所說的功能。
- **你投影的網站**，以及**教會設定的聖經譯本和服務**，由你自己選擇。
- **現場音訊：** 為了在裝置之間找到連線路徑，電腦和手機會向 STUN 伺服器（Google 的 `stun.l.google.com`）查詢自己的公開位址。Google 會看到這個位址，但看不到任何音訊內容。

**教會伺服器**由你的教會執行，而不是我們。它保存什麼（詩歌、備份、錄音、投影記錄等）由教會決定，請詢問負責的同工。本頁不涵蓋教會伺服器。

## 公共伺服器

`public.worship-q.com` 為沒有教會伺服器的電腦提供手機遙控、聖經經文、投影片轉換和現場音訊。它執行在 Amazon Web Services 位於英國倫敦的伺服器上，前面有 Amazon CloudFront。

### 經過伺服器的內容和保留時間

| 內容                                                          | 保留                                                                                                                  |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 你匯入的投影片、PDF 和照片，以及轉換出的投影片圖片            | 電腦確認已取得後立即刪除；未確認的一天內刪除                                                                          |
| 手機遙控的訊息、手機上顯示的投影片小圖，以及手機上的 OBS 畫面 | 不保存：只在電腦和手機都連線時中轉                                                                                    |
| 現場音訊                                                      | 不保存、不錄音：在電腦和最多兩位收聽者之間中轉。網路需要時，經過同一主機上的中繼伺服器（TURN）                        |
| 聖經經文                                                      | 經文出處會轉給 Free Use Bible API，對方看到的是我們的伺服器，而不是你。經文內容在記憶體中最多保留 10 分鐘，不與你關聯 |
| 詩歌、流程表、備份和錄音                                      | 從不傳送到公共伺服器                                                                                                  |

### 伺服器對你的電腦知道什麼

- **一個工作區編號和一把裝置金鑰**，都是隨機產生的，在電腦第一次使用公共伺服器時建立。金鑰只以雜湊的形式保存，並記錄最後使用的時間。它們都不包含你、你的教會或你的電腦的名稱。工作區 90 天未使用後即被刪除。
- **這份應用程式的隨機編號**，由電腦傳送，用來按每份應用程式計算限額（例如每天 100 份投影片和照片）。它只保存在記憶體中，保留時間不超過限額的計算週期（最長一天），從不寫入磁碟或日誌。
- **你的網路位址**，每個網際網路請求都會帶有。它保存在記憶體中，用來按位址計算限額，最長一天。

### 日誌

- 伺服器日誌為每個請求記錄時間、請求的內容（不含細節，所以沒有經文搜尋或出處）和結果。日誌不記錄你的網路位址，只有因達到限額而被拒絕的請求例外：那一行會記錄位址和所達到的限額。
- 中繼伺服器（TURN）會記錄它中轉音訊的每台裝置的位址。
- 日誌在 14 天後刪除。途中不保留其他存取日誌。

保留日誌只是為了維持服務運作和防止濫用，不作其他用途。

## 本網站

worship-q.com 託管在 GitHub Pages 上，GitHub 會保留自己的造訪日誌。我們使用 Cloudflare Web Analytics 統計造訪量：它不設定 Cookie，也不會跨網站追蹤你，我們只看到總數。本網站沒有表單，也不需要登入。
