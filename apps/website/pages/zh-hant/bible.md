# 聖經經文，隨時投影

講員臨時提到一段不在流程表中的經文？使用 Worship Q，幾秒鐘就能找到並顯示在投影螢幕上，還能並排顯示兩個聖經譯本。

![投影螢幕上的詩篇 23 篇，和合本與英王欽定本（KJV）並排顯示，附有經節編號](/screenshots/zh-hant/slideshow-bible.webp)

## 查找經文

- **直接輸入出處**：例如 `馬可福音15:5-6`、`可15:5-6`，也支援 `Mark 15:5-6` 等英文寫法。
- **依書卷查找**：先選擇書卷和章節，再選起始、結束經節；也可以跨章選取。
- **關鍵字搜尋**：例如輸入 `愛你們的仇敵`。能否使用關鍵字搜尋，取決於所選譯本。
- 在詩歌搜尋欄輸入經文出處，也能直接前往聖經查找頁面。

## 投影或加入流程表

- 選擇 **投影 ▶**，經文就會插入目前顯示項目的後面，並立即出現在投影螢幕上。
- 選擇 **加入流程表**，經文會加入相同位置，但不會立即顯示，適合事先準備稍後要讀的經文。
- 經文和詩歌一樣，都是流程表中的獨立項目。你可以調整順序、移除項目，或重新選擇經節與譯本。投影片會依完整經節分頁，並標示經節編號及譯本名稱。
- 經文可以使用獨立背景，不受詩歌背景設定影響。
- 使用手機遙控時，也可以臨時把經文加入正在使用的流程表。

## 兩個譯本，逐節對照

雙譯本模式會盡量讓相同的經節出現在同一張投影片上。若兩個譯本的經節劃分不同，例如某個譯本將兩節合併，Worship Q 會在操作介面中顯示說明，方便同工核對。這些說明不會出現在投影螢幕上。

## 支援哪些譯本？

經文功能需要連線教會自己的免費 Worship Q 伺服器（參見[伺服器設定](/server/#經文)）。不需要 API 金鑰，就能使用和合本、英王欽定本（KJV）、Berean Standard Bible 等譯本。教會也可以設定自行申請的 API 金鑰，使用 NIV（英式英語版）、NKJV、NLT、ESV 等其他譯本。

教會可以決定開放哪些譯本，每個工作區最多同時顯示兩個。

**已經加入流程表的經文，即使暫時斷網，也能繼續投影。**
