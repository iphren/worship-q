# Worship Q — 同工指南

诗歌和流程表都会保存在这台电脑上，备课和投影都不需要账号或互联网。手机遥控、圣经经文，以及 PowerPoint 或 PDF 幻灯片，第一次使用时会通过免费的 Worship Q 公共服务器进行，服务器不保留任何内容；这需要互联网。如果你的教会运行自己的 Worship Q 服务器，多台电脑就能同步投影并共享诗歌；见下面的 **多台电脑**。

## 1. 添加诗歌

1. 打开 **资源库**，选择 **添加诗歌**。
2. 输入标题，然后输入或粘贴歌词，每行一句。
3. 段落之间（主歌、副歌……）空一行。
4. **预览** 显示这首诗歌会怎样拆分。默认每两行成为一张幻灯片，所以一行中文接着同一行的英文，会显示在同一张幻灯片上。
5. 选择 **保存**。

## 2. 编排流程表

1. 打开 **日历**。日历会自动定位到下一个聚会日。
2. 在流程表下方搜索诗歌，点击即可加入。用 ↑ ↓ ✕ 调整顺序或移除。搜索框旁的 **置顶** 按钮会列出在资源库中置顶的项目，每周都用的项目一键就能加入。
3. 要沿用之前某一周的安排，点击那个日期，选择 **复制到…**。

其他日期是只读的，直到你在那个日期上选择 **编辑**。

## 3. 投影控制

1. 把投影仪或电视连接为第二个屏幕。
2. 打开 **投影控制**。在 **投影屏幕** 下选择投影仪，然后选择 **打开投影**。下次打开时，Worship Q 也会记住这个选择。要把投影移到另一个屏幕，先选择那个屏幕，再关闭投影并重新打开。或者选择 **窗口**，把投影拖到你要的屏幕上，再选择 **全屏**。
3. 应用启动后会进入 **投影控制** 页面，并自动启用相应日期的流程表：如果今天的流程表有诗歌，就是今天的；否则是下一个聚会日的。若要切换到其他日期的流程表，在日历中那个日期上选择 **启用**。
4. 点击任意一张幻灯片即可显示。↓ 和 ↑ 在当前诗歌的幻灯片之间逐张切换，→ 和 ← 移到下一首或上一首诗歌：它的标题会以靛蓝色突出显示，让你在显示之前就知道按键作用在哪一首。Enter 会顺着整份流程表往下走：下一张幻灯片，到了一首诗歌的最后一张之后，就是下一首的第一张。空格键隐藏内容但保留背景；再按一次空格键就显示同一张幻灯片。（空格键不会像在 PowerPoint 或 Keynote 中那样切到下一张。）Delete（Mac 笔记本上是 fn + delete）清屏，但仍在进行中；之后按 Enter 或 ↓ 会从第一张开始（清屏时空格键不起作用）。投影窗口在最前面时，这些按键同样有效。
5. 每首诗歌是一列，并排排列，幻灯片在列中由上往下，所以 ← 和 → 在诗歌之间横向移动，↓ 和 ↑ 在一首诗歌的幻灯片之间上下移动。可以用触控板、诗歌下方宽的滚动条，或在诗歌标题上滚动鼠标滚轮，在诗歌之间横向滚动；在幻灯片上滚动滚轮则上下滚动。窗口较窄时，诗歌会改为由上往下堆叠。**设置 → 投影界面与快捷键** 可以让它们始终堆叠，与早期版本相同；也可以交换方向键，让 ← 和 → 逐张切换幻灯片（并像视频播放器那样在视频中跳转），↓ 和 ↑ 在诗歌之间移动。当按键与布局相反时会有提醒：堆叠的诗歌配交换后的按键，并排的诗歌配默认的按键。

## 4. 聚会中修改歌词

选择诗歌上方的 **编辑**，修改文字或标题，然后 **保存**。屏幕会立即更新，并停在同一张幻灯片上。

幻灯片、PDF、照片和网站的 **编辑** 只能修改项目的标题；视频还有 **自动播放**。

## 5. 结束时

直接关闭应用，或选择 **清屏** 把歌词撤下。之后打开来编排的流程表：如果今天是聚会日，就总是今天的；否则是下一个聚会日的。所有内容随时自动保存；如果笔记本在聚会中途合上或重启，重新打开 Worship Q 会从原来的地方继续。

## 幻灯片、PDF、照片和视频

没有教会服务器时，**视频只保存在这台电脑上**：Worship Q 会保留一个副本，不需要互联网。**幻灯片、PDF 和照片** 由免费的 Worship Q 公共服务器转换，这台电脑取得后服务器就不再保留；其他电脑之后无法获取，也不提供 **下载原始文件** 和 **重新转换**。教会服务器会为工作区的每台电脑保留这些内容。

- **添加**：在 **资源库 → 媒体 → 添加媒体**；用流程表诗歌搜索旁边的媒体按钮（加在最后）；或者把文件从“访达”或“文件资源管理器”拖到流程表上：一条蓝线会显示它们将放在哪里。一次拖多个文件也可以。
- **两条进度条。** 首先，文件发送时会有一条进度条，并显示百分比。之后，服务器处理幻灯片、PDF 和照片时，会显示移动的条纹。视频一发送完就可以用；没有教会服务器时立即可用。在流程表中，进度条显示在项目本身上；在资源库中，显示在搜索框下方。这期间你可以转到其他页面。发送时按 ✕ 可以取消；如果出了问题，会显示原因和 **重试**。
- **文件太大？** 消息会说明文件有多大，以及服务器接受多大。请导出一个较小的版本（视频用 H.264 编码的 MP4，到处都能播放），再添加一次。
- **iPhone 照片（HEIC）。** Mac 会自动把它们转成 JPEG。在 Windows 上，请先把照片导出为 JPEG，或把 iPhone 设为 **设置 → 相机 → 格式 → 兼容性最佳**。
- 每个流程表项目的 **⋯ 菜单** 有 **编辑…**（歌词、标题，或视频的标题和 **自动播放**）、**下载原始文件**、**上传新版本**（没有教会服务器时，视频为 **使用新版本**）和 **移除**。新版本会保留项目的标题，以及它在每份流程表中的位置；如果上传失败，什么都不会改变。

### 视频

连接教会服务器时，每台电脑都会提前下载今天和之后流程表中的视频；项目上的紫色进度条会显示下载情况，聚会中不会在线播放任何内容。视频项目开始时是暂停的，除非在它的编辑窗口中打开了 **自动播放**。视频进行中时，幻灯片上方会有一条控制栏，可以播放、暂停和拖动进度，手机上也有同样的控制栏。按键也会改变：空格键播放或暂停，↑ 和 ↓ 后退或前进 10 秒。← 和 → 照常移到另一项，按 Enter 可切换到下一项。中途离开视频去读经，回来时会从原来的地方继续。隐藏内容会暂停视频；重新显示就会继续。启用另一份流程表后，视频的播放位置会被清除。

**旧视频。** Worship Q 打开半小时后，会删除只用于过去流程表、或已不在任何项目中的视频副本。教会服务器上也有的副本会直接删除：需要时会再下载回来。只存在于这台电脑上的副本，不经询问绝不删除：横幅会说明这些视频占用了多少空间，并提供 **查看…**（列出这些视频，每个都可以用 **打开** 播放）和 **忽略**。取消勾选要保留的视频，然后选择 **删除所选**。只会删除 Worship Q 的副本，绝不会删除你当初添加的文件。保留的视频 30 天内不会再次提示；这类视频占用不到 100 MB 时不会显示横幅。

视频声音从投影窗口播放。在 **设置 → 这台电脑的音频** 中选择播放设备；应用会请求一次使用麦克风的权限，只用来列出你的音频设备。浏览器投影页面和 OBS 也会播放声音。浏览器可能要等你点击页面后才播放声音：在那之前视频会静音播放，并提示点击以播放声音。

**YouTube 视频。** 网站项目如果是一个 YouTube 视频的链接，就只显示视频本身，并像视频项目一样控制：同样的控制栏、按键和手机控制，并从链接指定的时间开始播放（`?t=90`）。添加时会从 YouTube 读取视频长度；在长度未知时，以及直播时，控制栏只能播放和暂停。有些视频不允许在 YouTube 以外播放，控制栏会提示。

## 经文

讲员读到不在流程表中的经文时，点击“投影控制”页面（或日历的流程表编辑器）中诗歌搜索旁边的 **书本** 按钮。

- **直接输入**，按你平常的写法：`马可福音15:5-6`、`可15:5-6`，也可以用英文，例如 `Mark 15:5-6`。或者 **浏览**：先选书卷，再选章，再选第一节和最后一节（同一节选两次，就只显示那一节）。**继续到第…章** 可以把范围延伸到下一章。不是经文出处的字词，例如 `爱你们的仇敌`，停顿一下后会在圣经中搜索。
- **预览** 会把工作区所用的译本并排显示。确认无误后：
  - **投影 ▶** 把经文加在屏幕上当前项目的后面，并立即显示。屏幕上没有内容时，会加在流程表的最后。
  - **加入流程表**（或 Enter）把经文放在同样的位置但不显示，适合讲员稍后才读的经文。在日历中只提供“加入”。
- 在诗歌搜索中输入经文出处，例如 `马可福音15:5`，诗歌上方会出现 **在圣经中打开马可福音15:5**，圣经按钮也会闪烁：点击它或按 Enter，就会在那里打开圣经。
- **译本** 是搜索框旁边的标签：**✕** 移除一个，**◀** 让它先显示，**+** 从教会提供的译本中添加一个，最多两个。译本属于工作区，所以每台电脑都一样；它们也在 **设置 → 圣经译本** 中。
- 经文是一个带青色书本标记的 **流程表项目**。可以像其他项目一样移动或移除；**编辑…** 会在圣经窗口中打开它，修改经节或译本，并保持它的位置。修改工作区的译本，不会改变已经加入的经文。
- **经文下方的说明**（ⓘ）会解释它为什么可能与讲员的圣经看起来不同：有的译本把两节合成一节（当代译本把历代志上 16:12–13 合并），有的译本没有某一节（NIVUK 没有启示录 12:18）。屏幕上从不显示这些说明。
- 经文有 **自己的背景**：**设置 → 背景 → 圣经** 为所有经文设定一个背景，与诗歌的背景分开。在你另选之前是黑色，或者选择 **投影背景** 使用工作区的背景。那里的 **添加图片或视频…** 会添加一个新文件，并马上用作经文的背景。
- 经文 **不会显示在字幕上**。要在直播中显示经文，请把 OBS 切换到有幻灯片的场景。
- 新的经文需要互联网：通过教会的服务器，或没有教会服务器时通过免费的 Worship Q 公共服务器，它提供无需密钥的译本（例如 KJV、BSB 和和合本）。流程表中已有的经文即使断网也能投影。
- 在 **手机** 上，**编辑 → 添加经文** 也能做同样的事，只是不能修改已经加入的经文。在手机的资源库搜索中输入经文出处，也会出现 **在圣经中打开…**。

## 设置

**设置** 中有你的聚会日、每张幻灯片行数、投影字体、文字大小和背景（颜色、图片或循环播放的视频），以及 **备份**：把整个工作区保存到一个文件，你可以把它放在安全的地方。

## 多台电脑

当电脑连接到你教会的服务器（**设置 → 教会连接**）时，它们会同步使用同一套投影内容。最先开始投影的电脑负责主控，其他电脑自动跟随，在自己的屏幕上显示同一张幻灯片。任何人都可以在其中任何一台上点击幻灯片、打开另一个日期的流程表，或编辑进行中的流程表；其他操作员会在横幅中看到修改。

- **接管投影控制**（设置 → 教会连接）让这台电脑主控投影。任何屏幕上的内容都不会改变。
- 如果主控投影的电脑出了故障，其他电脑会显示 **主控投影的电脑没有响应。** 在其中一台上选择 **在这里继续**：它会从同一张幻灯片继续。第一台电脑恢复后，会改为跟随。
- **仅观看模式**（设置）适用于只需跟随的投影电脑：它只同步显示投影画面，不会主动开始或接管投影。重新打开后仍处于仅观看模式。没有正在进行的投影时，它显示 **正在等待投影**。
- 场地没有互联网时，连在同一个 Wi-Fi 上的电脑仍可通过局域网保持投影同步。设置中会说明每台电脑的连接方式：**在局域网上** 或 **通过教会服务器连接**。

要连接一台新电脑，在 **设置 → 教会连接** 中输入服务器地址和这台电脑的名称，然后选择 **下一步**。电脑会显示一个代码；你教会的一位管理员在浏览器中批准后，电脑就会连接。如果教会给你的是连接码，请选择 **我有连接码**。

## 教会的诗歌

当你的教会共享一个资源库时，来自它的诗歌会带有 **教会** 标记。你可以直接将它们用于投影。如果你修改了其中一首，你的修改会成为你工作区自己的版本：教会的版本对其他人保持不变，这首诗歌会显示 **2 个版本**。诗歌的背景不同：它是你工作区自己的选择，所以修改背景不会产生新版本，教会之后对这首诗歌的修改仍会同步给你。要给一首诗歌换上新的图片或视频，打开它，在 **设置** 标签中选择 **这首诗歌自己的背景**，再点击 **添加图片或视频…**。

打开有两个版本的诗歌，顶部会有一个切换：**原始版本**（教会的）和 **我们的版本**。原始版本是只读的；我们的版本可以编辑，切换旁边的 **删除我们的版本** 会永久删除它，回到教会的诗歌。选择这个工作区投影时使用的版本，然后按 **保存**：和其他修改一样，选择要保存后才生效。它只适用于这个工作区中的这首诗歌，你工作区的每台电脑都会跟随。如果教会删除了它的版本，这首诗歌只会显示你们的版本，直到教会恢复它的版本。

移除教会的诗歌只会在你的工作区中隐藏它；教会和其他工作区仍保留它。

## 手机

在任何一台电脑上，打开侧边栏底部的手机图标。扫描二维码的手机会请求控制权，并显示一个四位数代码；代码相符时就批准它。之后，这部手机可以配合工作区的每台电脑使用，直到有人选择 **断开** 或 **全部断开**。

没有教会服务器时，手机通过免费的 Worship Q 公共服务器连接，因此电脑和手机都需要互联网。最多可同时连接两部手机，最多两部手机收听现场音频。

## OBS

Worship Q 可以替你在 OBS 中切换场景、直播和录制，在工作区的任何一台电脑上和手机上都可以操作。

**在运行 OBS 的电脑上设置一次。** 在 OBS 中打开 **工具 → WebSocket 服务器设置**，勾选**开启 WebSocket 服务器**，然后点击 **应用**。接着在 Worship Q 中打开 **设置 → OBS**，打开 **在这台电脑上控制 OBS**。Worship Q 会尽量自己读取 OBS 的密码；如果提示需要密码，请在 OBS 中点击 **显示连接信息**，把密码复制到设置中。为 **切换按钮** 选择两个场景，例如歌词场景和摄像机场景。这台电脑可以是观看端。

**聚会中。** OBS 连接时，“投影控制”页面的幻灯片上方会有一个直播画面的小预览，下面是切换按钮，旁边显示 **直播**、**录制** 和 **虚拟摄像机** 是否开启。**流程表** 和 **投影** 旁边的 **OBS** 标签页列出每个场景，并可以开始和停止 **直播**、**录制** 和 **虚拟摄像机**。手机在流程表标题下方的一行中也有同样的功能。圆点表示连接状态：绿色已连接，琥珀色正在连接，灰色表示 OBS 没有运行，红色表示被拒绝。停止直播或录制前会先询问。

OBS 和 Worship Q 哪个先打开都可以。如果另一台电脑打开了它自己的 OBS 连接，就会接管，这台电脑则会关闭；再次打开即可收回。关闭连接会让所有地方的 OBS 控制都消失。

## 现场音频

一台电脑可以把调音台的声音发送给其他电脑、手机和教会的管理员，让在场外的人也能及时切换幻灯片。

**在接了调音台信号的电脑上设置一次。** 通过音频接口或 USB 输入把调音台接到电脑上，不要用电脑自带的麦克风，它收到的是房间里的声音。在 **设置 → 这台电脑的音频** 中，把它选为 **音频输入**，然后打开**广播现场音频**。调音台送出声音时，留意 **输入电平** 是否跳动。这样就好了：从此每次打开 Worship Q，这台电脑都会自动广播，即使音频接口稍后才插上。请关闭这台电脑的屏幕锁定；广播期间 Worship Q 会让显示器保持唤醒。教会录制现场音频期间，这个广播也会被录制在教会的服务器上，开关下方的文字会说明这一点。

**状态的意思。** **直播中** 后面是收听人数；**正在等待输入** 表示所选的音频接口没有插上，插上后声音会自动恢复；**麦克风被拒绝** 表示必须在系统的隐私设置中允许 Worship Q；**请把这个窗口显示出来** 表示窗口被最小化或遮住了，在看到窗口之前系统不会启动麦克风。

**收听。** 在其他任何一台电脑上，“投影控制”页面会显示带耳机按钮的 **收听**；收听时按钮会变成停止图标。在你按下之前不会播放任何声音，重启后也会恢复为关闭。声音在设置中选择的 **收听播放于** 设备上播放，例如你的耳机，收听时也可以更改。手机在流程表标题下方也有同样的按钮。旁边的数字是网络和缓冲的延迟，以及 **直连** 或 **中继**。最多十人可以同时收听。

**在手机上，** 屏幕锁定或浏览器转到后台时，声音可能会停止。收听时请保持屏幕开启，并让浏览器在最前面。

如果另一台电脑打开了 **广播现场音频**，它会接管，这台电脑则会关闭；再次打开即可收回。

## 浏览器远程画面和已连接的设备

**设置 → 浏览器远程画面** 可以创建一个链接，在任何浏览器中，或在没有安装 Worship Q 的电脑上的 OBS 中，显示投影或字幕。链接创建时请复制下来；它只显示一次。**撤销** 链接即可停用它。在这台电脑上，OBS 可以用那里显示的地址，在没有互联网的情况下显示投影。

**设置 → 已连接的设备** 列出所有正在同步投影的设备，手机和浏览器远程画面旁边有 **断开**。
