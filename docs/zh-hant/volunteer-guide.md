# Worship Q — 同工指南

詩歌和流程表都會儲存在這台電腦上，單機使用不需要帳號或網際網路。如果你的教會執行 Worship Q 伺服器，多台電腦就能同步投影，也可以使用手機遙控；見下面的 **多台電腦**。

## 1. 新增詩歌

1. 開啟 **資源庫**，選擇 **新增詩歌**。
2. 輸入標題，然後輸入或貼上歌詞，每行一句。
3. 段落之間（主歌、副歌……）空一行。
4. **預覽** 顯示這首詩歌會怎樣拆分。預設每兩行成為一張投影片，所以一行中文接著同一行的英文，會顯示在同一張投影片上。
5. 選擇 **儲存**。

## 2. 編排流程表

1. 開啟 **日曆**。日曆會自動定位到下一個聚會日。
2. 在流程表下方搜尋詩歌，點選即可加入。用 ↑ ↓ ✕ 調整順序或移除。搜尋框旁的 **置頂** 按鈕會列出在資源庫中置頂的項目，每週都用的項目一鍵就能加入。
3. 要沿用之前某一週的安排，點選那個日期，選擇 **複製到…**。

其他日期目前為唯讀，直到你在那個日期上選擇 **編輯**。

## 3. 投影控制

1. 把投影儀或電視連線為第二個螢幕。
2. 開啟 **投影控制**。在 **投影螢幕** 下選擇投影儀，然後選擇 **開啟投影**。下次開啟時，Worship Q 也會記住這項選擇。要把投影移到另一個螢幕，先選擇那個螢幕，再關閉投影並重新開啟。或者選擇 **視窗**，把投影拖到你要的螢幕上，再選擇 **全螢幕**。
3. 應用程式啟動後會進入 **投影控制** 頁面，並自動啟用對應日期的流程表：如果今天的流程表有詩歌，就是今天的；否則是下一個聚會日的。若要切換到其他日期的流程表，在日曆中那個日期上選擇 **啟用**。
4. 點選任意一張投影片即可顯示。↓ 和 ↑ 在目前詩歌的投影片之間逐張切換，→ 和 ← 移到下一首或上一首詩歌：它的標題會以靛藍色突出顯示，讓你在顯示之前就知道按鍵作用在哪一首。Enter 會順著整份流程表往下走：下一張投影片，到了一首詩歌的最後一張之後，就是下一首的第一張。空格鍵隱藏內容但保留背景；再按一次空格鍵就顯示同一張投影片。（空格鍵不會像在 PowerPoint 或 Keynote 中那樣切到下一張。）Delete（Mac 筆記本上是 fn + delete）清除畫面，但仍在進行中；之後按 Enter 或 ↓ 會從第一張開始（清除畫面時空格鍵不起作用）。投影視窗在最前面時，這些按鍵同樣有效。
5. 每首詩歌是一列，並排排列，投影片在列中由上往下，所以 ← 和 → 在詩歌之間橫向移動，↓ 和 ↑ 在一首詩歌的投影片之間上下移動。可以用觸控板、詩歌下方寬的捲軸，或在詩歌標題上滾動滑鼠滾輪，在詩歌之間橫向滾動；在投影片上滾動滾輪則上下滾動。視窗較窄時，詩歌會改為由上往下堆疊。**設定 → 投影介面與快捷鍵** 可以讓它們始終堆疊，與早期版本相同；也可以交換方向鍵，讓 ← 和 → 逐張切換投影片（並像影片播放器那樣在影片中跳轉），↓ 和 ↑ 在詩歌之間移動。當按鍵與佈局相反時會有提醒：堆疊的詩歌配交換後的按鍵，並排的詩歌配預設的按鍵。

## 4. 聚會中修改歌詞

選擇詩歌上方的 **編輯**，修改文字或標題，然後 **儲存**。螢幕會立即更新，並停在同一張投影片上。

投影片、PDF、照片和網站的 **編輯** 只能修改項目的標題；影片還有 **自動播放**。

## 5. 結束時

直接關閉應用程式，或選擇 **清除畫面** 把歌詞撤下。之後開啟來編排的流程表：如果今天是聚會日，就總是今天的；否則是下一個聚會日的。所有內容隨時自動儲存；如果筆記本在聚會中途合上或重啟，重新開啟 Worship Q 會從原來的地方繼續。

## 投影片、PDF、照片和影片

這些需要你教會的 Worship Q 伺服器（見 **多台電腦**）。

- **新增**：在 **資源庫 → 媒體 → 新增媒體**；用流程表詩歌搜尋旁邊的媒體按鈕（加在最後）；或者把檔案從「訪達」或「檔案資源管理器」拖到流程表上：一條藍線會顯示它們將放在哪裡。一次拖多個檔案也可以。
- **兩條進度條。** 首先，檔案傳送時會有一條進度條，並顯示百分比。之後，教會伺服器處理投影片、PDF 和照片時，會顯示移動的條紋。影片一發送完就可以用。在流程表中，進度條顯示在項目本身上；在資源庫中，顯示在搜尋框下方。這期間你可以轉到其他頁面。傳送時按 ✕ 可以取消；如果出了問題，會顯示原因和 **重試**。
- **檔案太大？** 訊息會說明檔案有多大，以及伺服器接受多大。請匯出一個較小的版本（影片用 H.264 編碼的 MP4，到處都能播放），再新增一次。
- **iPhone 照片（HEIC）。** Mac 會自動把它們轉成 JPEG。在 Windows 上，請先把照片匯出為 JPEG，或把 iPhone 設為 **設定 → 相機 → 格式 → 相容性最佳**。
- 每個流程表項目的 **⋯ 選單** 有 **編輯…**（歌詞、標題，或影片的標題和 **自動播放**）、**下載原始檔案**、**上傳新版本** 和 **移除**。新版本會保留項目的標題，以及它在每份流程表中的位置；如果上傳失敗，什麼都不會改變。

### 影片

每台電腦都會提前下載今天和之後流程表中的影片；項目上的紫色進度條會顯示下載情況，聚會中不會線上播放任何內容。影片項目開始時是暫停的，除非在它的編輯視窗中打開了 **自動播放**。影片進行中時，投影片上方會有一條控制欄，可以播放、暫停和拖曳進度，手機上也有同樣的控制欄。按鍵也會改變：空格鍵播放或暫停，↑ 和 ↓ 後退或前進 10 秒。← 和 → 照常移到另一項，按 Enter 可以切換到下一項。中途離開影片去讀經，回來時會從原來的地方繼續。隱藏內容會暫停影片；重新顯示就會繼續。結束投影後，影片的播放位置會被清除。

影片聲音從投影視窗播放。在 **設定 → 這台電腦的音訊** 中選擇播放裝置；應用程式會請求一次使用麥克風的權限，只用來列出你的音訊裝置。瀏覽器投影頁面和 OBS 也會播放聲音。瀏覽器可能要等你點選頁面後才播放聲音：在那之前影片會靜音播放，並提示點選以播放聲音。

## 經文

講員讀到不在流程表中的經文時，點選「投影控制」頁面（或日曆的流程表編輯器）中詩歌搜尋旁邊的 **書本** 按鈕。

- **直接輸入**，按你平常的寫法：`馬可福音15:5-6`、`可15:5-6`，也可以用英文，例如 `Mark 15:5-6`。或者 **瀏覽**：先選書卷，再選章，再選第一節和最後一節（同一節選兩次，就只顯示那一節）。**繼續到第…章** 可以把範圍延伸到下一章。不是經文出處的字詞，例如 `愛你們的仇敵`，停頓一下後會在聖經中搜索。
- **預覽** 會把工作區所用的譯本並排顯示。確認無誤後：
  - **投影 ▶** 把經文加在螢幕上目前項目的後面，並立即顯示。螢幕上沒有內容時，會加在流程表的最後。
  - **加入流程表**（或 Enter）把經文放在同樣的位置但不顯示，適合講員稍後才讀的經文。在日曆中只提供「加入」。
- 在詩歌搜尋中輸入經文出處，例如 `馬可福音15:5`，詩歌上方會出現 **在聖經中開啟馬可福音15:5**，聖經按鈕也會閃爍：點選它或按 Enter，就會在那裡開啟聖經。
- **譯本** 是搜尋框旁邊的標籤：**✕** 移除一個，**◀** 讓它先顯示，**+** 從教會提供的譯本中新增一個，最多兩個。譯本屬於工作區，所以每台電腦都一樣；它們也在 **設定 → 聖經譯本** 中。
- 經文是一個帶青色書本標記的 **流程表項目**。可以像其他項目一樣移動或移除；**編輯…** 會在聖經視窗中開啟它，修改經節或譯本，並保持它的位置。修改工作區的譯本，不會改變已經加入的經文。
- **經文下方的說明**（ⓘ）會解釋它為什麼可能與講員的聖經看起來不同：有的譯本把兩節合成一節（當代譯本把歷代志上 16:12–13 合併），有的譯本沒有某一節（NIVUK 沒有啟示錄 12:18）。螢幕上從不顯示這些說明。
- 經文有 **自己的背景**：**設定 → 背景 → 聖經** 為所有經文設定一個背景，與詩歌的背景分開。在你另選之前是黑色，或者選擇 **投影背景** 使用工作區的背景。
- 經文 **不會顯示在字幕上**。要在直播中顯示經文，請把 OBS 切換到有投影片的場景。
- 新的經文需要教會伺服器；流程表中已有的經文即使斷網也能投影。
- 在 **手機** 上，**編輯 → 新增經文** 也能做同樣的事，只是不能修改已經加入的經文。在手機的資源庫搜尋中輸入經文出處，也會出現 **在聖經中開啟…**。

## 設定

**設定** 中有你的聚會日、每張投影片行數、投影字型、文字大小和背景（顏色、圖片或迴圈播放的影片），以及 **備份**：把整個工作區儲存到一個檔案，你可以把它放在安全的地方。

## 多台電腦

當電腦連線到你教會的伺服器（**設定 → 教會連線**）時，它們會同步使用同一套投影內容。最先開始投影的電腦負責主控，其他電腦自動跟隨，在自己的螢幕上顯示同一張投影片。任何人都可以在其中任何一台上點選投影片、開啟另一個日期的流程表，或編輯進行中的流程表；其他操作員會在橫幅中看到修改。

- **接管投影控制**（設定 → 教會連線）讓這台電腦主控投影。任何螢幕上的內容都不會改變。
- 如果主控投影的電腦出了故障，其他電腦會顯示 **主控投影的電腦沒有回應。** 在其中一台上選擇 **在這裡繼續**：它會從同一張投影片繼續。第一台電腦恢復後，會改為跟隨。
- **僅觀看模式**（設定）適用於只需跟隨的投影電腦：它只同步顯示投影畫面，不會主動開始或接管投影。重新開啟後仍維持僅觀看模式。沒有正在進行的投影時，它顯示 **正在等待投影**。
- 場地沒有網際網路時，連在同一個 Wi-Fi 上的電腦仍可透過區域網路維持投影同步。設定中會說明每台電腦的連線方式：**在區域網路上** 或 **透過教會伺服器連線**。

要連線一台新電腦，在 **設定 → 教會連線** 中輸入伺服器位址和這台電腦的名稱，然後選擇 **下一步**。電腦會顯示一個代碼；你教會的一位管理員在瀏覽器中批准後，電腦就會連線。如果教會給你的是連線碼，請選擇 **我有連線碼**。

## 教會的詩歌

當你的教會共享一個資源庫時，來自它的詩歌會帶有 **教會** 標記。你可以直接將這些詩歌用於投影。如果你修改了其中一首，你的修改會成為你工作區自己的版本：教會的版本對其他人保持不變，這首詩歌會顯示 **2 個版本**。詩歌的背景不同：它是你工作區自己的選擇，所以修改背景不會產生新版本，教會之後對這首詩歌的修改仍會同步給你。

開啟有兩個版本的詩歌，頂部會有一個切換：**原始版本**（教會的）和 **我們的版本**。原始版本為唯讀；我們的版本可以編輯，切換旁邊的 **刪除我們的版本** 會永久刪除它，回到教會的詩歌。選擇這個工作區投影時使用的版本，然後按 **儲存**：和其他修改一樣，選擇要儲存後才生效。它只適用於這個工作區中的這首詩歌，你工作區的每台電腦都會跟隨。如果教會刪除了它的版本，這首詩歌只會顯示你們的版本，直到教會恢復它的版本。

移除教會的詩歌只會在你的工作區中隱藏它；教會和其他工作區仍保留它。

## 手機

在任何一台電腦上，開啟側邊欄底部的手機圖示。掃描 QR 碼的手機會請求控制權，並顯示一個四位數代碼；代碼相符時就批准它。之後，這部手機可以配合工作區的每台電腦使用，直到有人選擇 **斷開** 或 **全部斷開**。

## OBS

Worship Q 可以替你在 OBS 中切換場景、直播和錄製，在工作區的任何一台電腦上和手機上都可以操作。

**在執行 OBS 的電腦上設定一次。** 在 OBS 中開啟 **工具 → WebSocket 伺服器設定**，勾選**開啟 WebSocket 伺服器**，然後點選 **套用**。接著在 Worship Q 中開啟 **設定 → OBS**，開啟 **在這台電腦上控制 OBS**。Worship Q 會盡量自己讀取 OBS 的密碼；如果提示需要密碼，請在 OBS 中點選 **顯示連線資訊**，把密碼複製到設定中。為 **切換按鈕** 選擇兩個場景，例如歌詞場景和攝影機場景。這台電腦可以是觀看端。

**聚會中。** OBS 連線時，「投影控制」頁面的投影片上方會有一個直播畫面的小預覽，下面是切換按鈕，旁邊顯示 **直播**、**錄製** 和 **虛擬攝影機** 是否開啟。**流程表** 和 **投影** 旁邊的 **OBS** 標籤頁列出每個場景，並可以開始和停止 **直播**、**錄製** 和 **虛擬攝影機**。手機在流程表標題下方的一行中也有同樣的功能。圓點表示連線狀態：綠色已連線，琥珀色正在連線，灰色表示 OBS 沒有執行，紅色表示被拒絕。停止直播或錄製前會先詢問。

OBS 和 Worship Q 哪個先開啟都可以。如果另一台電腦打開了它自己的 OBS 連線，就會接管，這台電腦則會關閉；再次開啟即可收回。關閉連線會讓所有地方的 OBS 控制都消失。

## 現場音訊

一台電腦可以把調音台的聲音傳送給其他電腦、手機和教會的管理員，讓在場外的人也能及時切換投影片。

**在接了調音台訊號的電腦上設定一次。** 透過音訊介面或 USB 輸入把調音台接到電腦上，不要用電腦內建的麥克風，它收到的是房間裡的聲音。在 **設定 → 這台電腦的音訊** 中，把它選為 **音訊輸入**，然後開啟**廣播現場音訊**。調音台送出聲音時，留意 **輸入音量** 是否跳動。這樣就好了：從此每次開啟 Worship Q，這台電腦都會自動廣播，即使音訊介面稍後才插上。請關閉這台電腦的螢幕鎖定；廣播期間 Worship Q 會讓顯示器保持喚醒。教會錄製現場音訊期間，這個廣播也會被錄製在教會的伺服器上，開關下方的文字會說明這一點。

**狀態的意思。** **直播中** 後面是收聽人數；**正在等待輸入** 表示所選的音訊介面沒有插上，插上後聲音會自動恢復；**麥克風被拒絕** 表示必須在系統的隱私設定中允許 Worship Q；**請把這個視窗顯示出來** 表示視窗被最小化或遮住了，在看到視窗之前系統不會啟動麥克風。

**收聽。** 在其他任何一台電腦上，「投影控制」頁面會顯示帶耳機按鈕的 **收聽**；收聽時按鈕會變成停止圖示。在你按下之前不會播放任何聲音，重啟後也會恢復為關閉。聲音在設定中選擇的 **收聽播放於** 裝置上播放，例如你的耳機，收聽時也可以更改。手機在流程表標題下方也有同樣的按鈕。旁邊的數字是網路和緩衝的延遲，以及 **直連** 或 **中繼**。最多十人可以同時收聽。

**在手機上，** 螢幕鎖定或瀏覽器轉到後台時，聲音可能會停止。收聽時請保持螢幕開啟，並讓瀏覽器在最前面。

如果另一台電腦打開了 **廣播現場音訊**，它會接管，這台電腦則會關閉；再次開啟即可收回。

## 瀏覽器遠端畫面和已連線的裝置

**設定 → 瀏覽器遠端畫面** 可以建立一個連結，在任何瀏覽器中，或在沒有安裝 Worship Q 的電腦上的 OBS 中，顯示投影或字幕。連結建立時請複製下來；它只顯示一次。**撤銷** 連結即可停用它。在這台電腦上，OBS 可以用那裡顯示的地址，在沒有網際網路的情況下顯示投影。

**設定 → 已連線的裝置** 列出所有正在同步投影的裝置，手機和瀏覽器遠端畫面旁邊有 **斷開**。
